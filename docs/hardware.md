## 2. Кремний

| Компонент | Роль | Комментарий |
|---|---|---|
| **Qualcomm Snapdragon AR1** | основной SoC | камера, ISP, on-device AI, Wi-Fi |
| **Bestechnic BES2700H** | компаньон | маломощный Bluetooth-аудио |
| **Qualcomm WCN7851** | Wi-Fi 6 | |
| **Kingston ePoP** | DRAM + flash | один BGA-корпус |
| PMIC | Qualcomm PMAR2130 | питание |

Ключевое следствие: **BES2700H — не главный процессор**. Камера, система и secure boot
находятся на AR1. Поэтому методики взлома браслетов на BES (Mi Band 9/10) напрямую
не переносятся: там взламывали именно BES, здесь он лишь аудио-компаньон.

## 3. Операционная система

Очки работают на **openvela** — открытой версии Xiaomi Vela, RTOS на базе **NuttX**.
Тот же класс системы, что в браслетах, часах и TWS-наушниках Xiaomi.

Следствия:

| Свойство | Телефон (Android) | Очки (openvela) |
|---|---|---|
| Среда исполнения APK | ART/Dalvik | отсутствует |
| Пакетный менеджер | есть | отсутствует |
| Приложения | отдельные APK | всё слито в один образ прошивки |
| Режимы прошивки | fastboot / recovery / EDL | нет |
| Отладка | ADB | ADB есть в коде, но выключен и закрыт |

Исходники платформы открыты (github.com/open-vela), но **BSP под конкретную плату
очков** и ключи подписи — нет.

## 4. Версии прошивки

| Версия | Дата (по публикациям) | Что добавила |
|---|---|---|
| 1.2.31.0 | 8 сентября 2025 | Alipay «взгляд-оплата» |
| 1.3.13.0 | октябрь 2025 | Bilibili-стрим, hands-free звонки, проверка качества кадра; **исправлен баг неограниченной длительности записи** |

Известные ограничения и настройки:

- длительность видеофрагмента: **15 с, 1, 2, 3, 5, 10 минут** (пресеты приложения);
- в версии до 1.3.13.0, если длительность не выбирать вручную, лимита не было;
- проверка «LED закрыт» использует камеру + датчик освещённости + датчик приближения
  и принудительно выключает камеру.

## 5. USB-идентификация

```
VID:PID         2717:50BD        (2717 = Xiaomi)
REV             0510
Класс           Camera (0x0e), SubClass 0x03, Prot 0x00
Интерфейс       MI_00 (единственный)
Драйвер         usbvideo
BusReported     MAC:04:34:C3:4F:01:8C-Xiaomi AI Glasses 018C
Серийный        63791/DYAMJQ5WA00105
```

Устройство составное (`usbccgp`), но функциональный интерфейс только один — UVC-камера.
Через USB доступен только видеопоток: ни ADB, ни CDC, ни vendor-каналов.

## 6. Почему прошивка — отдельная история

Перепрошивка требует трёх независимых условий:

1. **Режим прошивки.** У телефона есть fastboot/recovery/EDL. У очков нет ни одного
   публично известного способа перевести устройство в режим приёма прошивки.
2. **Образ, который примет загрузчик.** Snapdragon AR1 использует secure boot:
   подпись проверяется до запуска. Ключи только у Xiaomi.
3. **Документация на плату.** Нужны карта памяти, клоки, драйверы дисплея/камеры/тача.
   Публичного BSP для AR1 в очках нет.

### Сравнение с Mi Band

| Критерий | Mi Band 8/9/10 | Xiaomi AI Glasses |
|---|---|---|
| ОС | Vela/NuttX | Vela/NuttX |
| Канал записи | UART/SWD, тестовые пятаки | не найден |
| SDK | утёкший SDK родственного чипа | нет |
| Загрузчик | утёкший SecondStage BSL | нет |
| Pinout | опубликован сообществом | нет |
| Сообщество | годы работы, тысячи людей | единицы |
| Результат | кастомная прошивка, DOOM | нет |

То есть «RTOS» — не приговор. Приговор — отсутствие канала, SDK и сообщества.

### История с ADB

Исследователь `idootop` (проект MigicCube) получил ADB на очках, эксплуатируя
уязвимость, и сообщил о ней Xiaomi. Уязвимость закрыли; на новых прошивках ADB
недоступен. Его собственный экземпляр сохранил доступ, потому что ADB был включён
до патча. Он же рекомендует Rokid/RayNeo как платформы, где отладка и sideload
разрешены официально.

## 7. Что можно делать без прошивки

| Задача | Как |
|---|---|
| Использовать как веб-камеру | UVC-поток по USB |
| Записывать видео без лимита 10 минут | писать поток на ПК |
| Менять настройки | локальный HTTP API (порт 8080) |
| Смотреть live-стрим | `/v1/live/{deviceId}/...` |
| Управлять по BLE | спаривание + реверс протокола |
